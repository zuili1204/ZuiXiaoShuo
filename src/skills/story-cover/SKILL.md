# 小说封面设计

## 流程

1. **读取定位**：书名、题材、目标读者、平台尺寸、核心情绪、主要视觉母题和禁忌。
2. **选择单一记忆点**：优先一个能代表作品冲突或关系的主视觉，不把所有设定塞进画面。
3. **检查题材识别**：让构图与色彩服务题材，不依赖参考书封面的人物、构图或标志性元素。
4. **预留文字区**：明确标题、作者名和安全边距；图像模型不擅长准确排字时，背景生成与文字排版分开。
5. **输出提示词**：主体、动作、环境、构图、视角、光线、色彩、材质和风格；另给负面约束。
6. **生成与检查**：有图像工具时按平台比例生成，检查主体、文字区、变形、无关文字和缩略图辨识度。
7. **保存与排版**：只有资产实际保存成功后才给本地路径；未生成时明确交付的是提示词，不说“封面已完成”。

## 输出

```markdown
# 封面概念
- 核心记忆点与题材信号：
- 目标平台与尺寸：
- 构图和文字安全区：
- 配色与字体建议：

# 图像提示词
# 负面约束
# 文字排版方案
# 生成结果（仅实际生成后填写路径）
```

## 验收

- 缩成平台列表缩略图后，主视觉和标题是否仍清楚？
- 画面是否传达本书而不是泛用“漂亮人物＋霓虹背景”？
- 是否避免未经授权的商标、角色形象和艺术家风格模仿？
- 书名与作者名是否由可靠排版工具叠加，而非依赖图像模型猜字？
