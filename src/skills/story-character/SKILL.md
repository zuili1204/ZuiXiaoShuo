# 人物与关系设计

## 流程

1. **确定故事功能**：人物在主线中承担什么压力、帮助、对照或视角，不只写标签。
2. **写清内在驱动**：当前目标、长期欲望、核心恐惧、错误信念或坚持；功能角色可以简单，不强制人人有成长弧。
3. **设计行动语言**：人物如何表达关心、争取利益、回避冲突、处理失败和作出选择。用行动区分人物，而不只靠外貌和口癖。
4. **设计声音**：句长、措辞、称呼、直接程度、回避方式和不会说的话；网络梗不能成为所有人的共同语言。
5. **建立关系状态机**：记录当前关系、双方各自理解、升级条件、退化条件、不可接受之事和下一次可能变化。
6. **做同事件测试**：让主要人物面对同一诱惑、委屈或误会，写出不同处理；遮住姓名仍应能辨认。
7. **检查独立生活**：重要角色应有与主角无关的任务、资源和选择，不只负责证明主角魅力。

## 输出

```markdown
# 人物卡
- 姓名 / 故事功能 / 当前状态
- 当前目标 / 长期欲望 / 核心恐惧
- 优势与局限
- 表达关心的方式
- 面对冲突的策略
- 语言节奏与称呼习惯
- 不会做的事 / 不会说的话
- 可采用的弧光：成长 / 平弧 / 堕落 / 揭示 / 无明确弧
- 本章或本卷的主动选择

# 关系卡
- 双方及各自目标
- 当前标签与双方认知差
- 已有共同经历
- 升级 / 退化条件
- 关系中的实际成本
- 下一枚可观察刻度：新信息、新权限、新责任或新承诺
```

## 验收

- 人物是否通过选择展示性格，而不是由作者宣布“温柔、聪明、偏执”？
- 情绪反应之后是否产生行动或关系变化，而不是重复脸红、震惊、吐槽？
- 强制亲密、预知或读心机制移除后，关系是否仍有现实依据？
- 重要角色是否有拒绝主角的能力与理由？
