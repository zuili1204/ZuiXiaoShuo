# 下一章续写

## 输入优先级

1. 作者本轮明确修改的方向。
2. 已写正文和上一章结尾。
3. 当前章纲、卷纲和人物/世界设定。
4. 章节摘要、追踪状态和待回收伏笔。

旧纲与正文冲突时以正文为事实，指出需要重订的未写规划，不用旧纲覆盖已发生事件。

## 流程

1. **确认承接点**：时间、地点、主视角、在场人物、身体状态、手中物件、各自认知和未完成动作。
2. **确认本章任务**：主角现在要推进什么，标题或上一章承诺必须兑现什么。
3. **列出本章增量**：任务结果、新事实、人物决定、关系新基线或情绪等待，至少一项。
4. **写场景**：按“触发 → 选择 → 即时结果”推进；不要让主角无故拖延，也不要靠路人反复夸赞制造进展。
5. **处理信息差**：只写当前视角能感知的信息；人物根据各自知道的内容产生合理误判。
6. **完成一个阶段结果**：可以小，但必须真实；章尾留下下一章需要处理的行动、信息、选择或后果。
7. **通读衔接**：首段不得假装上一章结尾不存在，末段不得总结本章意义。

## 语言与反应

- 延续本书既有视角、句长、口吻和题材基调。
- 重要对白要影响下一句或下一步行动；反应不必层层堆满。
- 日常章可以低压，但至少保留关系、信息或期待增量。
- 强情绪段落减少吐槽与解释，让动作和停顿自己成立。

## 停靠与输出

- 未指定数量时只写 1 章；多章请求逐章根据实际新正文更新状态。
- 细纲缺失但上下文足够时，先给极简章纲再继续；关键事实缺失时先问。
- 默认只输出正文，不附摘要、检查表或下一章方案。
- 没有保存工具或工具未成功时，不宣称已经写入章节或更新追踪。
