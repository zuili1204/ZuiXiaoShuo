# 灵感孵化

## 目标

把“一个感觉很酷的点子”变成能反复产生场景、人物选择和读者期待的故事发动机。只设计原创故事，不把参考作品的人物、设定或桥段换名复用。

## 流程

1. **分开事实与空缺**：列出作者已确定的书名、题材、人物、禁忌和必须有；不得静默改名或改设定。
2. **只问关键问题**：最多问 3 个会改变主线方向的问题；其余以假设补全并明确标注。
3. **提炼核心发动机**：用一句话写清“谁，在什么处境下，反复遇到什么问题，会做出什么有看点的选择”。
4. **建立兑现清单**：把书名和简介承诺拆成首次可观察兑现、长期升级方向、最终回收方式。核心卖点必须能在前 3—5 章演示一次，而不是只被介绍。
5. **设计可重复单元**：至少列 3 个不同场景，证明该设定能持续制造事件；每个场景都要改变任务、信息、关系或情绪之一。
6. **检查人物自主性**：机制可以制造相遇和信息差，但不能替代信任、选择与情感积累。
7. **需要多方案时沿不同轴发散**：例如事件驱动、关系驱动、悬疑驱动，不把同一答案换三种措辞。

## 立项卡输出

- 书名：保留作者已给书名；需要备选时给 3 个。
- 题材与基调：
- 一句话梗概：
- 200 字内简介：具体人物、处境、核心机制、反复出现的场面、一个未解释的例外。
- 核心冲突：人物目标与阻力，不只写抽象主题。
- 3—5 个卖点：每个卖点对应一个可见场景。
- 故事发动机：触发 → 人物选择 → 即时结果 → 新状态。
- 开篇兑现表：承诺 / 首次兑现 / 后续升级。
- 主要角色与关系：只列必要角色。
- 假设与风险：信息不足、套路化、机制过强或关系缺乏现实依据等。

## 验收

- 能否立刻想象一个具体场面，而不只是几句形容词？
- 同一机制连续使用三次时，是否会产生不同问题，而非只换地点和对手？
- 主角是否有自己的目标，而不是只等系统、旁人或意外推着走？
- 是否保留了作者所有硬性要求？
