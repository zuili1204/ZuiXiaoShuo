# 立项卡片模板

```
【类型】玄幻 / 都市 / 悬疑 / 科幻 …
【基调】燃 / 虐 / 爽 / 治愈 / 暗黑
【核心冲突】某人(主角)想要 X，但 Y 阻碍，于是 Z。
【开篇钩子】<一句话反差或悬念>
【差异化卖点】
  1. 设定新奇度：…
  2. 情绪价值：…
  3. 爽点机制：…
【目标读者】…
```

## 开篇钩子范式（优先用 1-8）

1. **日常异常**：「周日早晨，他能看见别人头顶多了一行字。」
2. **关系错位**：「新同桌是我上周在便利店撞见的人，她装作不认识我。」
3. **规则可玩**：「这个能力有一个漏洞：同一个人，一周只能被用一次。」
4. **公共社死**：「他在全校早操时，看见了班主任头顶的颜色。」
5. **小生意开场**：「两元一次，抱一下，换一种情绪。」
6. **未解释的例外**：「所有人的颜色他都能看见，除了那个转学生。」
7. **误会链**：「她以为他在表白，他其实只是在试能力。」
8. **元叙事自嘲**：「如果这是轻小说，下一句应该是——可惜不是。」
9. **身份反差**（可选）：「堂堂仙尊，居然成了废柴赘婿。」
10. **真相崩塌**（可选）：「我养了十年的女儿，是仇人的孩子。」

> 死亡倒计时、能力代价、交易困局不是不能用，但它们属于“虐向/悬疑向”分支，不要作为默认开篇。默认先让读者看见一个好玩、可重复、能发生关系的场面。
