# 文风契约参考

## 元数据

- 来源用途：作者基准 / 外部参考 / 混合。
- 版本、语料哈希、总章数、抽样章数、抽样字符数。
- 分析模型或确定性工具、失败样本、整体置信度。

## 维度

| 维度 | 需要回答的问题 | 可执行产物 |
|---|---|---|
| 视角与时态 | 谁在看，叙述距离多远，何时切换 | 视角边界与例外 |
| 句式与段落 | 长短句如何分工，何处停顿 | 句段节奏规则，不设统一配额 |
| 词汇与语气 | 口语、书面、地域、时代与题材用语 | 偏好/回避词及语境 |
| 对白 | 对白密度、称呼、打断、潜台词与反应 | 对白推进规则 |
| 内心 | 直述、自由间接、吐槽或克制的使用位置 | 内心呈现规则 |
| 描写 | 环境、外貌、物件和动作如何服务场景 | 描写选择规则 |
| 幽默与严肃 | 笑点由什么构成，何时停止玩梗 | 基调切换规则 |
| 人物声音 | 不同功能角色如何选择措辞与行动 | 分角色声音卡 |
| 章节工程 | 标题承诺、开场、场景数、章尾方式 | 章节功能骨架 |
| 信息差 | 谁知道什么，揭示如何改变行动 | 信息揭示规则 |
| 关系推进 | 日常互动怎样留下新基线 | 关系状态机 |
| 具体性 | 抽象说明与具体细节如何配比 | 场内呈现规则 |
| 禁忌边界 | 作者明确不写的内容和套路 | 禁止项及适用范围 |

## 单条规则格式

```json
{
  "rule": "可执行写法",
  "evidence": ["短证据，外部参考须脱敏"],
  "confidence": 0.0,
  "tier": "must/should",
  "appliesTo": "适用题材、人物或场景",
  "exceptions": "何时不要应用"
}
```

只有多章稳定出现时才能考虑 `must`；单一样本或低置信观察使用 `should` 或留空。

## 评估输出

| 位置 | 维度 | 当前文本证据 | 契约依据 | 偏差影响 | 最小改句方向 |
|---|---|---|---|---|---|

另列“刻意偏离但应保留”的部分，避免把人物变化、题材变化和场景需求误判为风格漂移。
