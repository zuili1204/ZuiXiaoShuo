# 作者文风实验室

## 边界

- 只分析“怎么写”，不复用人物、关系、世界观、具体事件链或原句。
- 作者旧作可作为主要风格基准；外部参考只提炼机制，并按授权与隐私边界处理。
- 定量指标是描述工具，不是越高越好或越低越自然的评分。
- 相似度用于发现过度贴近和意外复用，不等于 AI 率、原创度或文学质量。
- 未实际运行指标或模型分析时，不编造数值、置信度和样本覆盖。

## 1. 导入与预检

1. 确认语料来源、用途、作者基准/外部参考、章节范围和是否允许保存。
2. 记录总章节、总字符、文本哈希或版本；同名附件以当前这次文件为准。
3. 清理网页残留、重复章节和非正文内容，保留原始语料，不覆盖。
4. 选择首、中、后段分层样本；报告 sampledChapters、totalChapters 和 sampledChars。

## 2. 全量定量与抽样定性

1. 对可用全量语料计算确定性指标，如句长、段长、对白、标点、词汇和章节结构。
2. 对分层样本逐章分析视角、叙述距离、对白反应、内心呈现、幽默、人物声音、章节工程和关系推进。
3. 每条定性结论带短证据与 confidence；证据涉及外部作品实体时先脱敏。
4. 部分样本失败时标出覆盖下降；全部失败时停止，不生成看似完整的画像。

## 3. 聚合风格契约

按 `references/style-contract.md` 输出：
- 稳定习惯与可变范围。
- 可执行 do/don't 规则及证据。
- 不同功能角色的声音差异，而非全员同一口吻。
- 开篇、场景、章尾和关系推进的写法。
- 作者刻意保留的“不规范”习惯。
- 样本冲突、低置信项和适用题材边界。

规则必须由多次观察支持；单次巧合不升级为硬约束。画像先为草稿，作者审阅后才启用。

## 4. 风格锚点与脱敏

1. 锚点按对白、动作、描写、内心、过渡、章尾分类，选择短而典型的证据。
2. 外部参考默认使用抽象规则或改写锚点；作者自己的语料是否保留原文锚点由作者选择。
3. 落库前用完整实体表做确定性替换，覆盖所有字段和证据，不只处理高频角色。
4. 检查是否仍存在长引文、具体事件链和可识别专名；未通过则不入库。

## 5. 融合与应用

1. 多来源融合时说明各来源负责什么维度，避免把不同题材规则混成硬模板。
2. 强度只控制参考约束的存在感，不能覆盖当前作品事实、人物声音和作者本轮要求。
3. 写作时优先注入少量相关规则和锚点，不整份画像每章重复装入。
4. 先保证结构和事实，再做作者风格的第二次改句；只迁移针法，不带入样本素材。

## 6. 评估与迭代

- 对照同一作品不同章节，找出稳定风格和漂移位置。
- 报告具体维度、证据和修改建议，不只给一个总分。
- 发现与参考语料过度相似时优先改写，而不是用更多装饰掩盖。
- 语料变化后生成新画像版本，不覆盖旧版；作者确认后再切换绑定。
- 只有保存工具成功返回后才宣称画像、配方或评估记录已落库。
