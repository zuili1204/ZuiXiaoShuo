# 拆书：只提炼写法

## 核心边界

设定是线，风格是针法。产物必须回答“作者怎么写”，不是“这本书写了什么人物与世界”。

- 不把原书人名、地名、组织名、专有能力、具体事件链或简介换名写入模板。
- 不用原书角色阵容和世界观条目充当可复用资产；只保留功能位和抽象机制。
- 引用证据尽量短，并在落库前用完整实体表做代码级脱敏；只替换前 20 个高频名字不算完整脱敏。
- 抽样分析必须披露 sampled/total 和章节截断情况，不能把抽样模板称为全书逐章结论。
- 模型分析失败时标缺失或低置信，不用通用模板伪装完整结果。

## 1. 切章与采样

1. 记录作品、文本范围、总章数和采样规则。
2. 首章、早期兑现章、中段、后段必须覆盖；研究完整收束时再加入末章。
3. 每章记录实际读取长度；超长截断时标出，不能据此判断被截断部分。
4. 输出采样清单后再逐章分析。

## 2. 逐章提取写法

每章只提取可迁移项：

```json
{
  "chapterRef": "序号或标题标识",
  "coverage": "完整/截断及范围",
  "pov": "主视角与是否换视角",
  "sceneFunctions": ["本场在任务/信息/关系/情绪上的功能"],
  "beatPattern": ["触发→选择→反应→结果的抽象节拍"],
  "informationLayers": "角色与读者的信息差如何产生效果",
  "dialogueReactions": "对白后选择了哪些反应，如何影响下一拍",
  "emotionCausality": "情绪由什么事件引起，怎样形成新状态",
  "sentenceRhythm": "长短句、段落和对白节奏",
  "endingFunction": "行动/信息/选择/后果/软钩及其作用",
  "evidence": ["已脱敏的短证据"],
  "confidence": 0.0
}
```

人物只写“主角/搭档/对手/旁观者”等功能位；场景写抽象动作，不写原书专名。

## 3. 三次汇总

### 汇总 A：开篇与章节发动机
- 书名级承诺如何在前几章被验证。
- 常规演示与异常案例如何安排。
- 每章怎样产生小结果，并保留下一步期待。

### 汇总 B：人物、关系与信息差
- 不同功能角色如何通过行动策略和声音区分。
- 信息差如何造成误判、喜剧、悬念或情绪后果。
- 关系如何通过新信息、权限、责任或承诺形成新基线。

### 汇总 C：语言、节奏与反模式
- 视角距离、句段变化、对白密度、内心呈现、幽默与严肃场景的处理。
- 有效手法和重复后失效的手法都记录。
- 明确题材专属规律，不把多女主、公众弹幕、系统数值等局部做法泛化。

## 4. 脱敏与模板输出

落库前执行：
1. 汇总全部实体候选，不仅高频前 20。
2. 用代码或确定性替换检查报告、证据、JSON 和模板全部字段。
3. 再扫描专名、长引文和具体事件链；无法确认脱敏时拒绝落库。
4. 模板只保留：读者承诺公式、开篇功能骨架、抽象章节节拍、关系/信息状态机、文风契约、检查清单。
5. 若运行环境强制要求 `NovelTemplate` 字段，人物仅填通用功能位，世界观只填抽象机制需求，不填原书条目。

## 输出

- `chapters`：逐章写法分析与覆盖范围。
- `report`：可迁移手法、题材边界、反模式、证据与置信度。
- `template`：完全脱敏的结构/风格模板。
- `validation`：采样比例、截断、解析失败、实体脱敏和未覆盖范围。

只有写回成功后才报告模板已保存；不能因生成了 JSON 就宣称已经入库。
