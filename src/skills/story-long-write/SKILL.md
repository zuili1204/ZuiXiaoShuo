# 长篇网文创作

## 职责

本技能负责判断当前阶段、组织上下文和控制停靠点，不再重复维护所有专门技能的长规则。能调用其他技能时按下表路由；不能调用时，按本文件的精简流程完成当前一步。

## 先判断项目状态

1. 只有灵感或空项目：进入立项。
2. 有立项但缺人物/规则：补最小设定。
3. 有设定但缺规划：生成当前所需层级的大纲。
4. 有细纲无正文：写作者指定章节，默认 1 章。
5. 有正文需要续写：先召回当前事实和下一章承诺。
6. 有正文需要修改：先确定诊断还是改写，并保护原稿。

无法判断时，列出可选择的下一步，不自动连续生成整本书。

## 全阶段共同原则

### 读者承诺

- 把书名、简介、题材和上一章建立的期待列成承诺，安排首次兑现、阶段增量与最终回收。
- 核心卖点要在动态场景中产生结果，不靠人物讲解代替兑现。
- 每章至少让任务、信息、人物决定、关系或情绪期待之一发生变化；允许低压章，不允许无功能的重复章。

### 信息与视角

- 每个场景确定一个主视角；需要切换时用清楚边界，并给新视角独立目标。
- 为秘密记录“主角知道、他人知道、读者知道、谁会误判、何时揭示”。
- 揭示之后必须改变行动或关系，不能只补充背景。

### 场景与人物

- 写章前使用场景推进卡：当前任务 → 主角目标 → 具体阻力 → 人物选择 → 即时结果 → 新状态。
- 重要对白之后选择最准确的一至两种反应：回答/回避、动作、策略变化或新误解；不必动作、表情、心理、解释全部叠加。
- 人物通过不同的目标、处理方式和语言节奏区分，不让所有角色共享同一种吐槽和网络梗。
- 外在机制只能制造机会，信任、亲密和情感仍由现实选择挣得。

### 节奏与语言

- 短句用于对白、动作、揭示和停顿；因果、氛围与复杂情绪可用自然中长句。
- 笑点或爽点成立后停止重复认证；删去重复复述、重复情绪和解释已经明显的动作。
- 章尾可留行动、信息、选择或后果，不强制每章两个悬念，也不用总结升华代替问题。

## 精简执行流程

### 开书

1. 确认作者硬性要求与缺失项。
2. 完成最小立项、人物和规则。
3. 生成主线、分卷和当前需要的章纲。
4. 默认停在提案供作者确认；只有明确要求时才写正文。

### 写当前章

1. 读取本章细纲、上一章结尾、出场人物状态、相关规则和活跃伏笔。
2. 写场景推进卡，核对标题承诺与必须覆盖的 hooks。
3. 只写指定章节，保持本书视角、风格和字数要求。
4. 检查 hooks、事实、人物声音、关系增量和章尾待兑现事项。
5. 有保存/追踪工具时，成功后再提交正文和事实增量；无工具时只返回正文，不宣称已保存。

### 续写多章

- 必须由作者给出数量或明确日更范围；逐章完成“召回 → 写作 → 检查 → 沉淀”，下一章使用上一章实际写出的状态。
- 每章保留作者确认点；遇到细纲冲突、人物重大转向或质量门禁失败时暂停，不自动向后冲。

### 修改

先确认是结构修订、事实一致性、节奏还是表达问题。大范围改写前建议快照；改写后复核事实与后续影响。只诊断时不改原文，只润色时不改剧情。
