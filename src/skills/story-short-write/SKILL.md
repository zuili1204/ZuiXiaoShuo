# 短篇写作

## 原则

短篇以一个主要冲突和少量人物为中心，但不强制反转，也不把长篇的多线结构压缩进来。篇幅、视角、题材和结尾形式以作者要求为先。

## 流程

1. **确定篇幅与形态**：闪小说、微小说或短篇；作者未指定时先给一个合适范围，不套用固定字数。
2. **锁定核心变化**：写清人物想要什么、为什么现在必须行动、什么选择让结尾不同于开头。
3. **选择叙事焦点**：围绕一个主要场景或紧密关联的少量场景，删去不影响核心变化的支线。
4. **布置必要证据**：结尾需要的物件、话语、性格或信息提前出现，但不重复暗示。
5. **展开关键选择**：重要转折用动作、对白和后果呈现，不用概述跳过唯一重要的戏。
6. **收束**：结尾可以反转、揭示、决定、回证或留白；必须来自前文，不额外制造巧合。
7. **分轮精修**：先查结构和因果，再查人物声音与情绪，最后删解释和重复；只改表达时可使用 `story-deslop`。

## 输出

直接输出完整短篇正文，除非作者要求先看方案。不要在正文后附创作说明、质量评分或“下一章钩子”。

## 验收

- 删除任一支线后若更集中，是否应删？
- 转折是否由人物选择或已铺证据造成？
- 结尾是否改变了前文的含义，而非只追加金句？
- 是否没有为了反转而反转、为了字数而注水？
