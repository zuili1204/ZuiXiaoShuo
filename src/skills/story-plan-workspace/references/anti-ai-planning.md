# 规划层的反 AI 味准则

适用于 A1-A6。规划不是正文，但一样会露馅：读者不一定看见大纲，作者一眼就能看出“模板在说话”。

## 三个硬判断

1. **能不能拍出来**：梗概、卖点、章纲、钩子，都要能在脑子里出现一个具体地点、两个具体的人、一个正在发生的动作。写不出画面，就还是概念。
2. **有没有人做决定**：每个桥段至少有一个角色，在具体处境里做了一个会改变关系或局面的选择。只写“发生了一件事”不算。
3. **下一条为什么点开**：章末、卷末、单元末，要留下一个读者想追的具体问题、动作或画面。不能用“他暗暗发誓”“命运的齿轮开始转动”代替。

## 八种典型症状与改法

| 症状 | 长什么样 | 改成什么 |
| --- | --- | --- |
| 对称排比 | 一半……一半……；不是……而是……；既是……也是…… | 只留一半，另一半换成具体动作 |
| 抽象名词堆叠 | 成长、救赎、羁绊、宿命、温度、光芒 | 换成一个正在做的小动作或一件具体东西 |
| 功能位标签 | “功能：负责搞事”“缺口：缺爱” | 写他第一次出场时做了什么让人头疼的事 |
| 同型节奏 | 每章都是误会→解释→和好 | 事件章、关系章、信息章、失败章轮换 |
| 人物同一句式 | 每人都是“她外表……其实……” | 每人用一个不同的动作或物件出场 |
| 冲突同型 | 每卷都是“更强的敌人出现” | 关系冲突、信息冲突、规则冲突、自我冲突轮换 |
| 总结句结尾 | “这一刻，他终于明白了……” | 停在动作、没说完的话或一个画面上 |
| 万能形容词 | 震撼、惊艳、意味深长、难以言喻 | 写旁观者的具体反应或一个可数的变化 |
| 等长块 | 三条候选都在 200 字上下，起承转合也一样 | 一条短促收尾，一条展开到一个场面，长短错开 |
| 背景开场 | “某校高三男生 X，名下有楼却……”从身份与现状讲起 | 第一句就写他此刻正在做什么，背景留到后面补 |

## 决策密度

一个块算“有决定”，必须同时满足：

1. 一个具体角色；
2. 在具体处境里；
3. 做了一个会改变关系、信息或局面的选择；
4. 选择带来可见后果。

只是“发生了一件事”“他明白了”“两人关系升温”，都不算决定。整份方案里至少一半的块要有决定；卷首、卷末、转折章必须有。状态维持章也要有人做一个“不改变主线但暴露性格”的小选择。

## 评分口径（只看事实，不看形容词）

- 落点：N 个块里有几个停在总结/决心；
- 决策：N 个块里有几个出现角色做选择；
- 同型：最多的一种落点或冲突占几个；
- 重复：同一短语在几个位置重复；
- 档案：几个块在用“功能/缺口/关系标签”介绍人物。

报告问题时给出数量、位置与原文片段，不用“节奏偏慢”“人物扁平”这类无法核对的判断。

## 四步改写

1. 找总结句：把“他明白了/他决定了”换成他当场做了什么。
2. 找标签：把“功能/缺口/关系标签”换成第一次出场时的动作与台词。
3. 找对称：删掉后半句，用一件不对称的小事补位。
4. 找抽象：把“成长/羁绊/救赎”换成一个可数、可拿、可摔的东西。
5. 找等长：如果几条候选长度和句式都一样，至少把一条压短到两三句，让节奏有起伏。

## 证据要求

指出问题时必须带位置和原文片段，例如“第 3 章章末『他暗暗发誓』是总结句”，不能只说“节奏偏慢”“人物不够立体”。没有证据的判断视为无效建议。

## 对比对：同一意图的坏 / 好写法

坏：他必须在保护她的同时付出代价，这是他的宿命。
好：他把伞塞给她，自己转身跑进雨里；第二天她在他桌洞里发现那把伞，伞骨断了一根。

坏：两人关系逐渐升温，彼此产生了羁绊。
好：她开始把豆浆买成两杯，第二杯放在他桌角，不说话；第三天他没来，第二杯被同桌喝了。

坏：反派出现，主角陷入前所未有的危机。
好：晚自习停电，有人拧亮手电，光正好照在他藏在桌肚里的那张画上；全班回头看他。

## 禁止

- 禁止复用示例、作者锚点与对标作品中的人名、地名、专有名词与具体情节，只学结构与推进方式。
- 禁止用“代价/宿命/救赎/倒计时/全员告白/不伤任何人”收尾。
- 禁止把同一批候选写成同一答案的三种措辞；多条候选必须沿不同轴发散。
