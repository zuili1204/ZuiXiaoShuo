# 章骨架与 hooks

## 章骨架字段

| 字段 | 说明 | 约束 |
|---|---|---|
| `title` | 章名 | 不带“第 X 章”，不剧透结局，同卷不重复 |
| `hooks` | 本章必须发生的事件 | 1-3 条，可执行动作/冲突/信息揭示/转折 |
| `conflict` | 本章核心冲突 | 谁想要什么、谁阻挡 |
| `turn` | 转折/爽点/信息揭示 | 必须改变局面、关系或认知 |
| `payoff` | 本章落点 | 给读者一个阶段性结果或画面 |
| `endingType` | 章末类型 | 动作 / 台词 / 画面 / 信息 / 未完成动作 / 误会 |
| `targetWordCount` | 目标字数 | 500-20000 |

## hooks 类型

1. **行动钩**：主角主动做了一件事，结果超出预期。
2. **冲突钩**：对手出手，主角被迫应对。
3. **信息钩**：揭示一条改变判断的信息。
4. **反转钩**：原本的盟友/线索/目标发生翻转。
5. **关系钩**：互动让两人的关系标签发生变化（陌生→同桌→共享秘密→被误会）。
6. **场面钩**：一个公共场合里发生的可复用名场面（社团摆摊、值日、考试、节日）。
7. **误会钩**：信息差让旁人产生错误判断，制造喜剧或张力。
8. **日常仪式钩**：固定时间/地点/动作带来的熟悉感与微小变化。

不合格的 hooks：

- “主角很生气”“气氛紧张”“他决定变强”——抽象形容，不可执行。
- “为下一章做铺垫”——没有发生任何事。
- “揭示最终反派”——提前透支后文底牌。
- “主角付出了代价”——除非写清具体失去了什么、谁看见了、关系怎么变。

## 章末类型

| 类型 | 写法 | 例 |
|---|---|---|
| 动作 | 停在一个未完成的动作上 | 他把零件盒盖按回去，收据还在手里。 |
| 台词 | 停在一句会改变关系的话上 | “你刚才……是不是走神了？” |
| 画面 | 停在一个可见的物件/颜色/表情上 | 她袖口的手表带印，一直没退。 |
| 信息 | 停在一条新信息上 | 发票背面写着一个他不认识的名字。 |
| 未完成动作 | 停在“正要……” | 他刚抬起手，手机响了。 |
| 误会 | 停在旁人误解的瞬间 | 班主任在门口站了三秒。 |

禁止：总结、升华、点题、“这一刻他终于明白”、命运/注定式收束。

## 状态维持章

允许存在不解决核心冲突的章节，但必须至少发生一项：

- 关系标签变化（哪怕只是从“同学”变成“会互相带早饭的同学”）。
- 信息变化（读者或角色知道了一件新事）。
- 名场面入库（一个以后可以反复提起的场面）。
- 期待变化（读者开始等一个具体的东西）。

连续两章都只是“赶路/解释/铺垫”才判问题。

## 黄金三章检查（仅首卷前三章）

- **第 1 章**：尽快出现冲突或悬念；主角的目标与困境可见；章末留钩。
- **第 2 章**：兑现第一个小爽点或信息推进；让读者确认“这本书要讲什么”。
- **第 3 章**：给出更大的悬念或反转，建立追读理由；不要在第 3 章就把底牌打完。

## 过渡章限制

- 连续两章不得都是“赶路/解释/铺垫”。
- 过渡章必须至少完成一件事：推进关系标签、埋设伏笔、改变目标、留下可复用场面。
- 卷首章优先建立本卷目标与可重复单元；卷末章收束本卷并抛出下一卷钩子。

## 承接与留钩

- 每章开头承接上一章钩子的后果，不重复解释。
- 每章结尾留一个具体问题或未完成动作，而不是“欲知后事如何”。
- A4 的 `continuityNotes` 必须写明：承接哪条钩子、为下一章留哪条钩子、涉及哪些角色状态。
