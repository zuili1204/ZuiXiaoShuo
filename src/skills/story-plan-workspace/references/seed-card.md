# 立项书模板

立项书只写“能驱动连载”的信息，不写百科，也不写人物档案。

## 模板

```text
书名（备选）：
题材/标签：
一句话梗概：一个具体身份的人 + 他想做成的一件小事 + 一个会反复发生的场面 + 一个暂时不解释的例外
故事简介（200 字内）：用两三个具体场面串起来，不写主题词
核心冲突：谁和谁在什么事上拉扯；第一次冲突发生在哪个场面
主角：第一次出场在做什么；他最想要的具体东西；他卡住的现实处境；他反复做的一个小动作
关键配角：第一次出场时和主角发生了什么具体摩擦；他/她自己想要什么
世界观锚点（3-5 条，只列能反复制造事件的规则）：
连载单元（5 条以内，每条写成一句能拍出来的场面）：
关系状态机（角色 A ↔ 角色 B：当前状态 / 哪件事会推进 / 哪件事会退回）：
卖点（3-5 条，写成读者能复述的场面）：
基调：
目标读者：
```

## 三个硬检查

1. 每条信息能不能在脑子里出现一个地点、两个人、一个正在发生的动作。
2. 主角的欲望、处境和习惯，能不能在同一个场面里同时看见。
3. 五个连载单元里，至少有三个下周还能再发生一次。

## 五个功能位

设定不是用来惩罚主角的，而是用来让日常反复产生好戏。立项时至少覆盖 3 个：

1. **可见进度条**：读者能一眼看出关系或能力走到了哪一步。
2. **可重复仪式**：每周/每天都能再来一次的固定节目（摆摊、值日、社团、顺路）。
3. **合法亲密借口**：能力或规则让两个人必须靠近，但又不显得刻意。
4. **公开关系地图**：旁人能看见、会议论、会误会的身份与关系。
5. **元叙事安全阀**：角色可以吐槽套路、读者可以会心一笑的自嘲位。

## 坏 / 好对比

坏样本（概念与档案，写手无法开写）：

```text
一句话梗概：一个关于成长与救赎的温暖故事，少年在友情与宿命之间做出选择。
主角：欲望 / 阻碍 / 缺陷 / 初始状态 / 口头禅
关键配角：功能 / 缺口 / 与主角的关系标签
卖点：热血、治愈、反转、群像、成长
```

好样本（同一题材，落到场面上）：

```text
一句话梗概：她在校门口的旧书摊帮人补书，五块钱一次，直到同桌把一本撕掉扉页的旧书推过来。
主角：放学后留在旧书摊补书，五块钱一次；她想攒钱买一台旧唱机；可每次补日记，都会从书脊里抖出夹着的东西；被戳穿时就低头拆线，拆得满桌都是。
关键配角：同桌第一次来补书，把一本撕掉扉页的旧书推过来就走，第二天又自己坐回来；她想让有人先开口。
核心冲突：她靠补书赚钱，却从来不肯让人碰自己的旧笔记本；同桌偏要她补那本从旧书堆里捡来的日记。
连载单元：补词典、补日记、找绝版练习册、旧书被贴到公告栏、旧书摊误收一箱捐赠书。
卖点：一封没寄出的信被翻出来；五块钱一次的补书摊；整条走廊都在传那本缺页的日记。
```

样本中的角色、地点与事件全部虚构，禁止复用其中的人名、地名与情节。

## 检查

- 能不能立刻列出 5 个**可重复发生**的名场面，而不是 5 个只能发生一次的主线事件。
- 主角的欲望、处境与习惯是否都能在具体动作里看见，而不是靠字段清单说明。
- 关键配角第一次出场时，是否和主角发生了一件具体的事。
- 关系是否有明确的状态变化与推进条件。
- 世界观锚点是否每条都能反复制造事件，而不是只用于一次揭底。
- 卖点是否写成了场面，而不是“热血”“治愈”“反转”这类抽象词。
- 如果题材确实需要代价，写清它如何服务关系推进与喜剧节奏，而不是惩罚主角。
