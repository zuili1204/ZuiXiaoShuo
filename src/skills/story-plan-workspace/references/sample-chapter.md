# 章细纲样本：坏 / 好对比

样本只示范 hooks 的可执行程度，角色、地点与事件全部虚构，禁止复用。

## 坏样本（流水账）

```text
hook 1：主角来到学校。
hook 2：主角遇见同桌。
hook 3：两人发生对话。
hook 4：主角有所感悟。
hook 5：故事继续发展。
```

问题：每条都不是钩子，是事件类别；无法指导下一段正文，也无法判断写没写到位。

## 好样本（可直接开写）

```text
章目标：让读者知道“补书会翻出旧东西”，同时把同桌推到主角对面。
hook 1：旧书摊窗口，她把价目表压在玻璃下：补封皮 5 元，补内页 3 元；第一个客人递来一本缺了扉页的词典。
hook 2：她拆开书脊，夹层里掉出一封没写地址的信，手上的锥子停住。
hook 3：同桌排在第二个，把一本旧日记推过来就走；她翻开，第一页写着“别翻后面”。
hook 4：她追到楼梯口，同桌已经拐弯；她低头拆线，拆到第三本才停下。
hook 5：晚自习，同桌又坐回她旁边，桌上多了一瓶没开的汽水；她把信夹回书里。

continuityNotes：账本里已经有“欠一页”；同桌知道信在她手里，但不知道她看过；汽水是下一章的道具。
```

## 好 hook 的四个特征

1. 有具体地点或物件，读者能看见。
2. 有一个人做了动作或说了话，而不是“发生了一件事”。
3. 动作带来状态变化：关系、信息、处境至少变一项。
4. 最后一条把问题留给下一章，但不写“欲知后事如何”。

## 检查

- 遮住章名，只看 hooks，能不能复述这一章发生了什么。
- 五条 hook 是否至少有三条包含动作或台词。
- 最后一条是否留下一个具体未完成项（一句话、一个物件、一个动作）。
- continuityNotes 是否只写会影响后续的事实，不写感受与评价。
