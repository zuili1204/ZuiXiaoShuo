# 卷章纲样本：坏 / 好对比

样本只示范章骨架的信息密度与节奏变化，角色、地点与事件全部虚构，禁止复用。

## 坏样本（同型 + 总结）

```text
第 1 章 初遇：主角遇见女主，命运的齿轮开始转动。
第 2 章 冲突：两人发生误会，主角解释，误会解除。
第 3 章 加深：两人关系更进一步，主角暗下决心。
第 4 章 危机：反派出现，主角陷入困境。
第 5 章 反转：主角爆发，危机解除。
```

问题：五章共用一个节拍；每章结尾都是总结；没有可执行的动作与具体落点。

## 好样本（不同章型 + 停在画面上）

```text
第 1 章 五块钱一次：她在旧书摊窗口摆出价目表，第一个客人来补一本缺页的词典；落点是收钱时发现对方给的是游戏币。章末：她把游戏币夹进账本，写上“欠一页”。
第 2 章 撕掉的扉页：同桌把一本撕掉扉页的旧书推过来，她补到夹层时摸到一封信；落点是她把信原样夹回去。章末：第二天同桌又坐回原位，桌上多了一瓶没开的汽水。
第 3 章 公告栏：有人把匿名信贴到公告栏，全班围观；她第一次替自己说话，说那封不是她写的。落点：班主任让她中午去旧书摊说明。章末：旧书摊的门开着，台灯已经点亮。
第 4 章 旧书摊：她站在摊前，把一封没有地址的信举起来；落点：她在信尾看见自己母亲的名字。章末：她合上账本，手还按在封皮上。
第 5 章 没寄出的信：她从旧书里翻出那封信，决定不再替人补日记；落点：同桌来退钱。章末：她把五块钱推回去，说这次免费。
```

章型分布：事件章 / 关系章 / 公开事件章 / 信息揭示章 / 选择章。每章至少完成一项：公共事件、关系状态变化、信息揭示、可复用名场面。

## 每章骨架的最低信息量

```text
章名：
本章目标（读者看完要知道/感到什么）：
冲突（谁和谁在什么具体事上拉扯）：
转折（哪一步让局面变了）：
落点（这一章最后停在哪个人/物/决定上）：
章末类型（画面/动作/台词/信息/未完成动作/误会）：
可复用单元（如果这章好看，下周怎么再来一次）：
```

## 检查

- 连续五章的章末类型是否至少出现三种。
- 是否有两章使用了同一个“误会→解释→和好”节拍。
- 每章落点是否是一个具体动作或物件，而不是“暗下决心”。
- 首卷前三章是否分别完成了人物立住、规则立住、关系立住。
