# 题材与竞品扫描

## 证据边界

1. 先确认目标平台、地区、读者群和时间范围。
2. 有联网或用户提供榜单、销量、评论时，记录来源与日期；没有数据时只做定性分析，不给出“热度第一”“留存提高”等结论。
3. 区分三类内容：**观察到的数据**、**基于样本的推断**、**创作建议**。样本不能代表全平台时必须说明。
4. 参考作品只用于分析读者承诺、叙事机制和差异化，不复制其设定、人物、标题或桥段。

## 流程

1. **归类**：确定主类型、次类型、核心卖点和基调，避免只贴宽泛标签。
2. **扫描**：按相同平台和相近读者选择可比样本；记录样本选择理由与偏差。
3. **比较读者承诺**：比较开篇兑现、核心发动机、主角目标、情绪奖励、连载单元和常见疲劳点。
4. **寻找空位**：从人物处境、关系组合、叙事视角、机制限制、场景资源中寻找差异，不靠堆砌冷门名词。
5. **验证可写性**：为建议方向列出 3 个可重复场景和 1 个中期升级方向。
6. **给出选择**：说明每个方向适合的作者优势、主要风险和验证成本，不替作者假装确定市场结果。
