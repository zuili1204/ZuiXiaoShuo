# 章节快照

## 操作边界

- 快照只保护正文版本，不自动证明摘要、伏笔和大纲已同步。
- 创建、列举和对比可主动执行；恢复会覆盖当前正文，必须得到作者明确确认。
- 不删除历史快照，除非作者明确提出且了解范围。
- 工具未成功返回时，不宣称快照已创建或恢复。

## 创建

适用于大幅修订、整卷改写、完成本章、流水线写回和恢复前。

1. 确认作品与章节 ID，读取当前完整正文。
2. 空正文不创建无意义快照。
3. 选择来源：手动、自动、完成本章、流水线或恢复前。
4. 写成功后报告实际时间/版本标识；自动快照被限流时如实说明未新建。

## 查看与对比

1. 按时间列出版本和来源，最新优先。
2. 对比前确认基准版本与目标版本。
3. 输出事实变化、结构变化、人物/关系变化和表达变化，不只给字符差异。
4. 特别检查伏笔、伤势、认知、物件和章尾状态，防止恢复旧稿破坏后续连续性。

## 恢复

1. 展示将恢复的作品、章节、目标版本和当前版本差异。
2. 获得作者确认后，先强制创建“恢复前”快照。
3. 再写回目标正文；成功后刷新依赖该正文的摘要、检索与追踪。
4. 若后续章节依赖被恢复版本改变的事实，列出需复核范围，不自动批量修改。
5. 任一步失败则停止并报告当前实际状态，不能声称已回滚完整。

## 输出

- 创建：章节、版本标识、来源、是否实际新建。
- 对比：基准/目标、主要变化、连续性风险。
- 恢复：恢复前快照、目标版本、写回结果、待同步项。
