# 跨媒介改编

## 输入

原作范围、目标媒介、单集/单话时长或页数、目标受众、必须保留的场景与台词、允许改动程度。缺少原作正文时先索取，不凭书名续编。

## 共同流程

1. **确定原作事实**：人物目标、关键因果、信息揭示顺序、关系变化和不可删伏笔。
2. **选择改编单元**：一个单元有明确目标、转折和结果，不机械按原章切分。
3. **把内心改为媒介可表达内容**：动作、表情、视觉线索、声音、旁白或对白；不得让角色突然说出全部动机。
4. **重排而非只删**：需要合并人物或场景时说明因果如何保留，改变事实需作者确认。
5. **按媒介排版**：使用下列对应契约，不输出泛泛“改编建议”代替脚本。
6. **回查原作**：人名、主语、物件、伏笔和结尾待兑现事项一致。

## 短剧脚本

按“集 → 场 → 内外景/地点/时间 → 动作 → 台词”输出。
- 每场有可见目标和变化，时长服从用户要求。
- 反转频率按剧情需要，不强制每分钟一次。
- 内心旁白只在不可替代时使用，关键信息尽量可视化。

## 漫画分镜

按“页 → 格 → 景别/构图 → 画面动作 → 对白/ caption → 音效”输出。
- 每格只承担一个主要动作或信息。
- 用视线、前后格和页面转折控制揭示，不把整段小说描写塞入画面说明。

## 有声脚本

按“段落/场景 → 旁白 → 角色台词 → 音效/停顿”输出。
- 标明说话者与必要语气，避免连续无法辨认的多人对话。
- 视觉信息转成自然可听信息，不堆砌舞台说明。
- 音效服务空间、动作和转折，不给每句配效果。

## 附：改编记录

| 原位置 | 改编位置 | 保留/合并/删减/重排 | 理由 | 对伏笔与因果的影响 |
|---|---|---|---|---|

只输出脚本时不附记录也行，但作者要求审阅差异或改动事实时必须提供。未实际写入文件时，不宣称剧本已保存。
