# 弧线设计

## 先选弧型

- **成长弧**：人物改变处理问题的旧方式。
- **平弧**：人物坚持核心价值，环境和其他人因此改变。
- **堕落弧**：人物逐步越过自己的边界。
- **揭示弧**：人物未根本改变，但读者与他人逐步认识真实的人。
- **关系弧**：关系权限、责任、信任或承诺发生阶段变化。
- **情绪弧**：希望、怀疑、安心、愧疚等状态随事件形成可追踪的变化。

一本书可混用多种弧，不要求每个主要角色都有完整成长模板。

## 流程

1. **确定对象与范围**：人物、关系或主线；覆盖全书、一卷或一个单元。
2. **定义起止状态**：用可观察行为写“开始时怎样、结束时怎样”，不写抽象大词。
3. **列出变化条件**：哪些事实、选择或代价会推动变化，哪些事件只会重复原状态。
4. **布置关键节拍**：建立 → 试探 → 第一次有效选择 → 反复或误判 → 新证据 → 决定性选择 → 新基线。按题材增删，不机械凑齐。
5. **安排回证**：让早期动作、物件、话语或习惯在后期改变含义，形成回收。
6. **对齐主线**：每个关键节拍必须落到具体卷章范围，不能只画一条漂亮曲线。
7. **检查现实依据**：预知未来或外在机制制造的情绪浓度，必须由当下相处与选择逐步挣得。

## 验收

- 每次反复是否带来新信息、更高选择成本或不同处理方式？
- 关系是否只有接触尺度增加，却没有理解、信任或责任增加？
- 结局状态是否由人物选择造成，而非作者突然宣布成长？
