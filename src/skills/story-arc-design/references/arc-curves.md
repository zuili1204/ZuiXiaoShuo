# 经典弧光类型

1. **正向弧（成长）**：怯懦→勇敢。触发事件打破稳态，中点信念动摇，至暗时刻压力最大（可以是关系破裂、身份暴露或选择失败，不限于代价），终蜕变。
2. **负向弧（堕落）**：理想→偏执。多用于反派，被背叛/挫折逐步黑化。
3. **平弧（坚守）**：信念不变，世界因他改变。如不动如山的守护者。
4. **伪成长弧**：看似变了实则没变，常用于讽刺/悲剧。
