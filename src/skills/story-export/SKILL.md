# 小说导出

## 导出合同

开始前确认：
- 作品与范围：全书、指定卷或连续章节闭区间。
- 格式：`md`、`txt` 或 `docx`。
- 是否包含书名、章节标题和卷标题。
- 是否移除写作标记、场景卡、批注和工程指令。
- 保存位置与文件名；已存在同名文件时先确认是否覆盖。

## 流程

1. **收集章节**：按项目真实卷章顺序读取完整正文，核对范围起止和章节数量。
2. **检查缺失**：标出无正文、读取失败、重复章号或范围空洞；不得静默跳过。
3. **清理内容**：移除内部场景标记和创作指令，保留正文原有标点与段落。
4. **按格式转换**：
   - Markdown 可保留标题与合法强调。
   - TXT 去除 Markdown 标记，但不能误删正文符号。
   - DOCX 使用可靠文档库生成标题、段落和换页，不只改扩展名。
5. **写出文件**：使用合适文本或二进制写入方式；DOCX 不以纯文本伪装。
6. **验证**：确认文件存在、大小合理，并抽查首尾章、范围和标题；可读回时验证编码与段落。
7. **报告**：只有写出和验证成功后给实际路径、格式、章节数和缺失项。

## 输出报告

```markdown
- 作品与导出范围：
- 格式：
- 实际章节数：
- 跳过/缺失内容：
- 清理规则：
- 保存路径（仅成功后）：
- 验证结果：
```

## 禁止

- 不自动上传、发布、提交投稿或分享文件。
- 不把“计划导出”说成“已经导出”。
- 不在未确认时覆盖已有稿件。
- 不把内部细纲、质量报告、快照或追踪文件混入正文，除非作者明确要求。
